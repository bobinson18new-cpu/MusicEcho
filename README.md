# MusicEcho

MusicEcho este o aplicație Android simplă pentru redarea fișierelor audio locale.

## Funcții incluse
- Adăugarea unuia sau mai multor fișiere audio din telefon
- Bibliotecă locală de melodii
- Căutare în bibliotecă
- Redare, pauză și trecere la melodia anterioară/următoare
- Bară de progres și durată

## Construirea APK-ului
La fiecare actualizare pe ramura `main`, GitHub Actions încearcă să construiască automat aplicația.
Când compilarea reușește, APK-ul de test poate fi descărcat din:
**GitHub → Actions → Build MusicEcho APK → Artifacts → MusicEcho-debug-apk**.

Pachet Android: `com.musicecho.app`
